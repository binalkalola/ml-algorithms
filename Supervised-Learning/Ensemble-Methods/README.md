### **# Ensemble Methods**



This repository contains my practical exercises on \*\*Ensemble Learning\*\* using Python and Scikit-learn.



### **## Topics Covered**



1\. Wisdom of the Crowd

2\. Out-of-Bag (OOB) Score

3\. Feature Importance

4\. Bagging vs Boosting

5\. Learning Rate

6\. Stacking Ensemble

7\. Manual Bagging from Scratch



### **## Libraries Used**



\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- Scikit-learn

\- SciPy



### **## Dataset**



\- Iris Dataset

\- Breast Cancer Dataset

\- Make Moons Dataset



### **## Key Learning**



Learned how ensemble methods combine multiple models to improve prediction performance and explored Bagging, Boosting, Random Forest, and Stacking.
