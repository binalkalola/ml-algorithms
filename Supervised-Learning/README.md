# Supervised Learning

Supervised Learning is a type of Machine Learning where the model learns from **labeled data**.

The dataset contains input features (X) and a known target/output (y). The model learns the relationship between them and uses it to make predictions on new data.

## Types of Supervised Learning

### 1. Classification

Classification is used when the output is a category or class.

Examples:

* K-Nearest Neighbors (KNN)
* Logistic Regression
* Decision Tree
* Random Forest
* Naive Bayes
* Support Vector Machine (SVM)

### 2. Regression

Regression is used when the output is a continuous numerical value.

Examples:

* Linear Regression
* Decision Tree Regression
* Random Forest Regression
