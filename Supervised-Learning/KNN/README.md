# KNN Exercises
Hands-on exercises exploring K-Nearest Neighbors (KNN) — distance metrics, feature scaling, cosine vs Euclidean comparisons, K-value tuning, timing analysis, and KNN regression, implemented in NumPy and scikit-learn.

## 📘 Overview
This repository contains a set of hands-on exercises exploring the K-Nearest Neighbors (KNN) algorithm, covering both theory and practical implementation using Python.

## 📂 Contents
| Exercise | Topic |

|---|---|

| 1 | Build Your Own Profile Matrix — creating a feature matrix X and label vector y |

| 2 | Ruler Showdown — Euclidean, Manhattan, and Minkowski distance calculations |

| 3 | Predict Like a Human — manual vs code-based nearest neighbour prediction |

| 4 | Scaling Rescue Mission — effect of feature scaling on KNN results |

| 5 | Cosine vs Euclidean Showdown — comparing distance metrics for text-like data |

| 6 | K Sweep Investigation — finding the optimal K via train/test accuracy |

| 7 | Timing Experiment — how KNN prediction time scales with data size and dimensions |

| 8 | KNN House-Price Estimator — KNN regression on multi-feature housing data |

## 📈 Key Takeaways
- Distance metric choice significantly affects nearest-neighbour results.

- Unscaled features can distort distance calculations — standardization matters.

- The optimal K balances bias and variance (too low = overfitting, too high = underfitting).

- KNN prediction time grows with both dataset size and feature dimensionality.
